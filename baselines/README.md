# Baselines

Current per-function general-capability baseline selections and explicit gaps.

The simple baseline view may select one primary evidence family per function, while the underlying corpus remains one-to-many.

A selected primary is backed by a machine-readable artifact under `comparison-cells/`. The baseline layer is the human/current-selection view; the comparison-cell layer owns the explicit matched-observation identity and comparability structure. Raw metric payloads remain in `system-observations/`.

Baseline selection does not delete secondary evidence and does not create a global harness score.
