# VSM Harness Capability

> **Status: experimental**

Experimental evidence-backed research on **general functional capability** of autonomous agent harnesses, compared one VSM function at a time.

This repository is distinct from canonical VSM assessment. It does not redefine S1–S5 or the OpenSiro autonomy states, and benchmark performance does not change canonical assessment state.

The repository is being bootstrapped from the public `functional-capability-depth` experiment in `opensiro/vsm-harness-index`.

Cross-repository architecture and source-of-truth boundaries are documented in `opensiro/vsm-oss-organization/ECOSYSTEM.md`.
