## Direct-S4 closure

The Profile requires S4 evidence to be externally and prospectively oriented: relevant environmental/future distinctions must produce adaptation options that can return into present operational capability. The ALFWorld Principle Memory protocol establishes that chain:

1. **External operational evidence.** SkillRevise executes a separate calibration set in the ALFWorld environment and obtains environment/checker-facing execution evidence rather than relying only on internal reasoning.
2. **Reusable distinctions.** Principle Memory does not retain a raw trajectory as the adaptation itself. It stores reusable repair principles that encode when a repair pattern applies, the defect addressed, the behavior to induce, how to verify it, and when the pattern should not transfer.
3. **Persistent adaptation options.** The calibration phase absorbs a compact principle bank into persistent SkillRevise state.
4. **Prospective freeze.** That bank is frozen before the evaluation split. Evaluation-task feedback is not absorbed back into the bank, so the later result is not an online same-task repair loop disguised as held-out scoring.
5. **Return into later operation.** During later held-out ALFWorld operations, SkillRevise retrieves from the frozen bank and uses those previously formed adaptation principles in the operational skill-revision path.

The important S4 distinction is therefore not simply “the system learned.” The reviewed boundary converts environment-grounded evidence into reusable, applicability-bounded adaptation options **before** later operations, then returns those options into later capability under a frozen adaptation state.

```text
calibration environment / failures
        ↓
reusable applicability + repair + verification distinctions
        ↓
persistent Principle Memory
        ↓ freeze before later operations
held-out operational tasks
        ↓
principles retrieved into later skill-revision capability
```

This satisfies the current Profile's external-and-prospective adaptation requirement more strongly than the same-task maxrev3 result surface.
