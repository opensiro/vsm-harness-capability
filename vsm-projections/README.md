# VSM projections

Derived interpretations that apply authoritative Profile semantics to neutral observations.

A projection may state that an observation is direct, proxy, composed, irrelevant or insufficient for a VSM function at a declared boundary.

Projections reference raw observation IDs and must not duplicate the raw numeric/result payload.

This directory does not define S1–S5. `opensiro/vsm-harness-profile` remains authoritative.
