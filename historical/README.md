# Historical experiments

Frozen research history migrated from the predecessor `functional-capability-depth` experiment.

Expected historical material includes Batch 01, Batch 02, LoopX controlled-execution/preregistration artifacts and frozen synthesis snapshots.

These artifacts may explain methodology evolution, failed attempts and earlier hypotheses. They are **not** an active path for generating capability evidence.

- `SOURCE-REF` pins the predecessor repository revision used for extraction.
- `PREDECESSOR-SHA256SUMS.txt` preserves predecessor artifact checksums.
- `MIGRATED-OBSERVATION-IDS.txt` freezes the 53 observation IDs present at extraction. The active corpus may grow, but those migrated IDs must remain recoverable.
- `predecessor-tests/` preserves experiment-specific Index tests that lived outside the predecessor experiment subtree. They are historical, not active Capability CI.
